# Girocerto

Calculadora de preço de revenda que mostra o preço mínimo para você lucrar e compara com o preço do concorrente.

## O que ele faz

- Você informa o custo do produto, o frete (opcional), o lucro desejado em reais e o preço do concorrente.
- O Girocerto soma custo, frete e lucro e mostra o preço mínimo de venda.
- Ele compara com o concorrente e diz se o seu preço é competitivo ou está acima.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

1. Baixe ou clone este repositório.
2. Abra o arquivo index.html no navegador.
3. Preencha os campos e clique em calcular.
